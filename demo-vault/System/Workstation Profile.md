# 我的工作站档案

## 已确认板块

1. 目标任务：显示最近目标和每日任务。
2. 创作者后台：提供视频与内容发布后台的直达入口。
3. 数据仪表盘：显示最近完成和未完成的事项。
4. 私人知识库：连接 Obsidian，支持捕获、搜索、打开原笔记和本机相关性检索。
5. AI 私人管家：辅助规划、内容创作、复盘，并从知识库命中片段中生成带来源的回答。
6. 无限画布：自由摆放便签、任务和知识卡，并通过 `.canvas` 文件与 Obsidian 互通。

## 每日工作流

1. 早上只选出今天真正要完成的任务。
2. 工作中把临时想法收进收件箱，需要时再转为任务。
3. 用 AI 查询知识、拆解工作或起草内容；任何系统修改先确认再执行。
4. 晚上完成每日复盘，记录成果、卡点和明天第一步。

其他功能只有在这条链路出现真实阻塞时再增加。
