# 小黄的工作站 · v0.4.0 完成度审计

审计日期：2026-08-13

## 个人工作流

当前主流程已收敛为：今日任务 → 执行与快速捕获 → 每日复盘 → 明天第一步。首次设置只要求连接 Vault、建立第一项真实任务和测试模型，不再设置团队协作、需求问卷或独立工作站蓝图。

## 已实现并验证

- 任务：新建、完成、重开、删除、恢复，以及 AI 新建、完成、删除任务均写入本机活动记录；AI 修改依靠任务 ID 和完整标题双重定位，并在执行前展示确认卡。
- 复盘：按日期保存草稿，显示当天真实活动，安全写入 Obsidian 管理目录；用户已有同名笔记不会被覆盖，外部修改后会阻止旧版本回写。
- 收件箱：捕获内容可转为今日任务或归档，处理后不再反复显示为待整理。
- 知识库：本机只读扫描与检索，AI 只接收当前问题命中的少量片段，答案保留来源。
- 无限画布：铺满主区域，支持多连线、图片、视频、音频、PDF、文本附件、拖放与粘贴；附件保存到桌面应用数据目录，删除最后一个引用卡片时同步清理工作站副本。
- 桌面应用：固定本机 origin 保证重启持久化；API 请求使用会话令牌；API Key 在桌面版使用 Windows 安全存储；安装程序创建桌面快捷方式。
- 本机备份：只包含白名单状态，不包含 API Key、Vault 路径、笔记正文或画布附件文件。

## 主动保留的边界

- 不展示没有真实数据源的平台播放量、粉丝或收益。
- 不做团队协作、多人权限或云端账户系统。
- Obsidian 是私人知识库和可读写的长期记录，不承担所有应用状态。
- `.canvas` 文件只引用附件路径，不负责打包附件本体。
- AI 不能绕过确认直接删除或修改系统内容。

## 后续只在真实需要时增强

1. 根据一段时间的复盘记录生成周复盘，而不是先增加更多仪表盘。
2. 当关键词检索的实际校准结果不足时，再增加本机向量索引。
3. 当真实发布流程稳定后，再接入明确的平台数据接口。
